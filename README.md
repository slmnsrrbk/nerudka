# Прототип сайта бетонного завода

Кликабельный серый прототип (wireframe) по ТЗ: все типы страниц, каталог, гео-раздел,
калькуляторы, формы и режим аннотаций. Дизайна нет, только структура, блоки и логика.

Рабочее название компании: **БетонЗавод**. Все контакты, цены и реквизиты условные.

## Запуск

```bash
npm install
npm run dev        # дев-сервер, http://localhost:4321
npm run build      # сборка в dist/
npm run preview    # просмотр собранного прототипа
```

Портативная сборка (открывается с любого базового пути, годится для хостинга в подпапке
и для публикации прототипа заказчику):

```bash
npm run portable   # собирает dist/ и кладёт копию с относительными ссылками в dist-portable/
```

Проверки:

```bash
npm run check:links    # битые внутренние ссылки в dist/
npm run check:mobile   # горизонтальный скролл на 375px и ошибки JS (нужен запущенный preview)
npm run check:ui       # сценарии: калькулятор, согласие ПДн, список заявки, фильтры, аннотации
```

`check:mobile` и `check:ui` работают по адресу `http://localhost:4321`, запустите `npm run preview` в соседнем терминале.

## Стек

Astro (static) + Tailwind CSS v4. Бэкенда нет: формы показывают тост, список заявки лежит в `localStorage`.
Страницы каталога, посадок и гео генерируются из JSON через `getStaticPaths`.

## Структура

```
src/
  data/          все JSON с контентом и демо-данными
  lib/           price.ts (единый расчёт цены), catalog.ts, geo.ts, faq.ts, seo.ts, routes.ts
  layouts/       BaseLayout.astro
  components/
    layout/      Header, MegaMenu, Footer, MobileBar
    ui/          Block, Container, Btn, ImagePlaceholder, Breadcrumbs, PageHead, PriceTable, Accordion, Modals
    blocks/      переиспользуемые блоки страниц (Hero, PriceTabs, FaqBlock, CtaFinal, SeoText и другие)
    forms/       LeadForm с вариантами (обычная, КП, вопрос, отзыв, компактная)
    calc/        PriceCalc, VolumeCalc
    pages/       CategoryView, ProductView, PrototypeMap
  pages/         маршруты
  scripts/app.ts вся клиентская логика
```

## Данные

| Файл | Что описывает |
|---|---|
| `site.json` | название, телефоны, адрес, зоны доставки, скидки от объёма, реквизиты |
| `categories.json` | дерево категорий каталога |
| `products.json` | 28 позиций: марка, класс, П, F, W, наполнитель, цена, бейджи, назначения |
| `purposes.json` | 7 назначений для посадок и блока «подбор по задаче» |
| `geo.json` | 13 направлений: расстояние, время в пути, зона, соседние пункты |
| `services.json` | 4 услуги с таблицами техники и условиями |
| `projects.json`, `reviews.json`, `posts.json`, `promos.json`, `documents.json`, `faq.json`, `pages.json` | контент остальных разделов |

### Как добавить позицию

Добавьте объект в `products.json`. Автоматически появятся:
карточка продукта, строка в листинге своей категории, строка в прайсе,
попадание в посадки своей марки, своего класса и своих назначений, позиция в списке заявки.

### Как добавить населённый пункт

Добавьте объект в `geo.json`. Появится гео-страница `/dostavka/{slug}/`, строка в списке направлений
на `/dostavka/`, ссылка в блоке доставки на главной и перелинковка у соседей.

Цена с доставкой считается в одном месте: `src/lib/price.ts`. Этот же модуль используют калькулятор
на главной, калькулятор в карточке, `/calculator/` и переключатель зоны в прайсе.

## Режим аннотаций

Переключатель «Показать разметку» в верхней строке шапки. Включает рамки и ярлыки `H-02 · Hero с калькулятором`
у каждого блока и бейдж шаблона в углу экрана. Состояние хранится в `localStorage`.

## Карта прототипа

`/_prototype/` — список шаблонов T00–T20 с примерами, все URL по разделам и счётчики.
Страница закрыта от индексации и исключена из `sitemap.xml`, `robots.txt` содержит `Disallow: /`.

## Что сделано иначе, чем у конкурентов

- мини-калькулятор цены стоит в первом экране, а не в середине страницы;
- два входа в каталог: по виду смеси и по задаче (фундамент, стяжка, дорожки, забор, перекрытия, пол, отмостка);
- прайс на главной в табах, в прайс-листе есть переключатель «цена с доставкой в зону»;
- вместо таблицы «завод против перекупщика» блок «как проверить, что привезли весь объём»;
- гео-страница даёт расстояние, время в пути, цену доставки и прайс с уже включённой доставкой;
- вместо корзины «список заявки»: несколько позиций отправляются одной формой;
- отдельная страница «Юрлицам и застройщикам»;
- один свёрнутый SEO-блок внизу страницы вместо простыней между блоками.

## Решения по неоднозначностям ТЗ

- **Путь карточки продукта.** В ТЗ указан `/catalog/{category}/{product}/`, но категории вложенные,
  поэтому используется полный путь: `/catalog/beton/tovarnyj/m300-b22-5-granit/`. Комментарий `TODO(вопрос)`
  стоит в `src/lib/catalog.ts`.
- **`/_prototype/`.** Astro не маршрутизирует папки с подчёркиванием, поэтому служебная карта отдаётся
  через динамический маршрут `src/pages/[page].astro` со слугом `_prototype`.
- **Гео-демо.** В ТЗ 12 пунктов, в прототипе 13: добавлен Красногорск, чтобы у каждого пункта были соседи
  для перелинковки.

## Что не входит в прототип

Визуальный дизайн, фотографии, реальные тексты и цены, CMS и бэкенд, отправка форм,
настоящие карты и виджеты Яндекса, оплата онлайн.
